# SummerCamp

A small app displaying attending campers name & details.

## Installation

Install .NET 3.1 Core Runtime & Android SDK. Open via Visual Studio

```powershell
cd C:\Users\%user%\Documents\GitHub\SummerCamp
dotnet run --project .\SummerCamp\HyVo_Proj1SummerCampAPI\HyVo_Proj1SummerCampAPI.csproj --launch-profile HyVo_Proj1SummerCampAPI
```

```powershell
cd C:\Users\%user%\Documents\GitHub\SummerCamp
dotnet run --project .\SummerCamp\HyVo_Proj1SummerCampXF\HyVo_Proj1SummerCampXF.csproj --launch-profile HyVo_Proj1SummerCampXF
```
